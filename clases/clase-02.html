Clase 2: Control de Servomotores en ESP32

Objetivos de la clase

  • Programación C++ en ESP32 para el manejo de hardware.
  • Generación de señales PWM orientadas al control de servomotores (Articulaciones).
  • Lectura y escritura de datos por puerto Serial entre el ESP32 y Python utilizando pyserial
  • Lectura de un sensor de presencia (ultrasonido o infrarrojo)

1. Conexión y Consideraciones del ESP32

El ESP32 trabaja a 3.3V en sus pines GPIO, por lo que es importante alimentar los servomotores (como los SG90) desde una fuente externa de 5V adecuada, compartiendo la tierra (GND) común para evitar ruido eléctrico o reinicios en el microcontrolador.

  • PWM en ESP32: A diferencia de Arduino Uno, el ESP32 utiliza la librería ESP32Servo o canales LEDC configurables para generar los pulsos de control (frecuencia estándar de 50Hz para servos).

2. Código C++ para ESP32 (Control de Servos + Sensor)

Este código configura el servomotor y lee de manera concurrente un sensor ultrasónico, enviando la información por el puerto Serial.

#include <Servo.h>

Servo myservo;  // Crear objeto servo
const int trigPin = 5;
const int echoPin = 18;
const int servoPin = 13;

void setup() {
  Serial.begin(115200);
  myservo.attach(servoPin);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  // 1. Lectura del sensor ultrasónico
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  long duration = pulseIn(echoPin, HIGH);
  float distance = duration * 0.034 / 2; // Distancia en cm

  // Enviar datos por serial hacia la PC
  Serial.print("Distancia:");
  Serial.print(distance);
  Serial.println(" cm");

  // 2. Leer comandos entrantes desde Python por Serial
  if (Serial.available() > 0) {
    int angle = Serial.parseInt(); // Leer ángulo enviado
    if (angle >= 0 && angle <= 180) {
      myservo.write(angle);
    }
  }
  delay(100);
}

3. Comunicación Serial con Python (pyserial)

Para comunicar nuestro script de Python con el ESP32 y enviar consignas de posición o recibir la distancia del sensor, utilizamos la librería pyserial.

Instalación previa en tu entorno de desarrollo:

pip install pyserial

Ejemplo de script en Python:

import serial
import time

# Configurar el puerto serial (ajustar '/dev/ttyUSB0' o 'COM3' según corresponda)
arduino = serial.Serial(port='/dev/ttyUSB0', baudrate=115200, timeout=.1)

def enviar_angulo(angulo):
    arduino.write(f"{angulo}\n".encode())
    time.sleep(0.05)

try:
    while True:
        # Enviar un ángulo de prueba
        enviar_angulo(90)
        
        # Leer respuesta del ESP32
        data = arduino.readline().decode('utf-8').strip()
        if data:
            print(f"Recibido del ESP32: {data}")
            
        time.sleep(1)
except KeyboardInterrupt:
    print("Comunicación finalizada.")
