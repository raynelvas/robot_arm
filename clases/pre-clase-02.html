Ensamblaje del Brazo MeArm

Antes de la Clase 2 debes tener tu brazo robótico físico armado y con los servos calibrados a 90°. Sigue esta guía paso a paso.

Introducción

Esta guía te permitirá ensamblar el brazo robótico MeArm antes de la Clase 2. Los ensamblajes pueden tener ligeras variaciones según el kit o el modelo 3D que tengas disponible, así que tómate tu tiempo y verifica las piezas antes de atornillar.

⚠️ Nota importante: Puedes tomar como referencia los siguientes enlaces, pero ciertas piezas pueden diferir del modelo que tienes disponible.

Referencias externas

  • Manual oficial MeArm v1.0 (PDF)

Paso 1: Colocar los 4 servos en posición de 90°

Antes de ensamblar, todos los servos deben estar calibrados a 90° (posición central). Esto es crítico porque las piezas se atornillan al servo asumiendo esa posición. Si no lo haces, el brazo quedará desalineado desde el inicio.

Código de calibración (ESP32)

Sube el siguiente código a tu ESP32 con el servo conectado al GPIO 18. El servo se moverá a 0°, 90° y 180° para que verifiques su rango de movimiento.

// Requiere la librería ESP32Servo
#include <ESP32Servo.h>

Servo miServo; // Crear el objeto para controlar el servo

// Definir el pin GPIO al que está conectado el cable de señal del servo
const int pinServo = 18;

void setup() {
  Serial.begin(115200);
  delay(1000); // Pequeña pausa para que abra el puerto serie

  // Adjuntar el servo al pin
  miServo.attach(pinServo);
}

void loop() {
  // Posición 0 grados
  Serial.println("Moviendo a: 0 grados");
  miServo.write(0);
  delay(3000); // 3 segundos para observar el cero

  // Posición 90 grados (centro)
  Serial.println("Moviendo a: 90 grados");
  miServo.write(90);
  delay(3000); // 3 segundos para observar el centro

  // Posición 180 grados
  Serial.println("Moviendo a: 180 grados");
  miServo.write(180);
  delay(3000); // 3 segundos para observar el extremo opuesto
}
💡 Tips:
  • Repite este paso con cada uno de los 4 servos antes de ensamblarlos.
  • Después de calibrar, marca con un plumón la posición de 90° en el eje del servo.
  • Desconecta los servos antes de atornillar para evitar movimientos involuntarios.

Pasos de ensamblaje

Paso 2: Sujeción del servo de la base

Arma la sujeción del servo que irá en la base del robot.

Paso 3: Pernos y tuercas en la base acrílica

Coloca los pernos y tuercas en la base acrílica del robot.

Paso 4: Sujetar el servo a la base

Coloca el servo sujetado en el paso 2 sobre la base acrílica con los pernos del paso 3.

Paso 5: Servo horn + base giratoria

Arma el servo horn con la base giratoria donde se asentará el robot.

Paso 6: Ajustar pieza al servo (en 90°)

Ajusta la pieza del paso 5 al servo. El servo debe estar en 90°. Si no calza bien, repite este paso girando la pieza giratoria.

Paso 7: Guía intermedia del brazo

Coloca la guía intermedia del brazo y únela al paso 6.

Paso 8: Sujeción del hombro

Arma la sujeción del hombro del brazo y colócala en la posición indicada.

Paso 9: Unir piezas de los pasos 7 y 8

Junta la pieza del paso 8 y el paso 7. Debe calzar sin realizar esfuerzo. Caso contrario, repite el paso 6 girando la pieza giratoria.

Paso 10: Servo del codo

Arma el servo del codo del robot.

Paso 11: Unir servo del codo al brazo

Junta la pieza del paso 10 a la estructura del brazo robótico del paso 9.

Paso 12: Mecanismo del codo

Arma el mecanismo del codo del robot.

Paso 13: Mecanismo para el efector final

Arma el mecanismo para sujetar el efector final. Este termina de dar apoyo al codo del robot pero empieza el mecanismo por el brazo del robot.

Paso 14: Efector final (pinza)

Arma el efector final (pinza del brazo).

Paso 15: Unir efector final al brazo

Junta el efector final con el brazo robótico completo.

✅ Checklist antes de la Clase 2

  • Los 4 servos fueron calibrados a 90° antes de ensamblar.
  • El brazo se mueve libremente sin forzar ninguna articulación.
  • Todas las piezas quedaron firmes (sin tornillos flojos).
  • Los cables de los servos no están pellizcados por las piezas.
  • La base está estable y no se vuelca al mover el brazo.
  • Tienes identificados los GPIOs de cada servo (base, hombro, codo, pinza).
