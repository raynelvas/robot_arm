Clase 3 - Puente Serial ESP32 ↔ ROS 2

Objetivos de la clase

  • Creación de espacio de trabajo y paquetes con colcon y rclpy.
  • Creación de nodo puente en Python para comunicación Serial.
  • Suscripción a ángulos de articulación en ROS 2 y envío por Serial al ESP32 para mover los servos físicos.

1. Creación del Espacio de Trabajo (Workspace)

Un espacio de trabajo (workspace) en ROS 2 es una carpeta estructurada que contiene paquetes ROS 2, los cuales pueden estar escritos en Python o C++. Todos los paquetes se compilan y organizan dentro del workspace.

Para crear el directorio base de nuestro workspace (ros2_ws), ejecuta en la terminal:

mkdir -p ~/ros2_ws/src
cd ~/ros2_ws

En este punto, la estructura inicial del workspace contiene una única carpeta vacía src:

.
└── src/ (1 directory, 0 files)

2. Herramienta de Construcción: Colcon

¿Qué es colcon? Es la herramienta oficial y recomendada para construir, compilar y organizar workspaces en ROS 2.

Características principales de colcon:

  • Compila múltiples paquetes de forma paralela.
  • Detecta dependencias entre paquetes y respeta el orden de compilación.
  • Separa los archivos construidos en carpetas específicas.
  • Es extensible mediante plugins.

Instalación de colcon

sudo apt install python3-colcon-common-extensions

Comandos principales de colcon

Comando ¿Qué hace?
colcon build Compila todos los paquetes encontrados en src/
colcon build --packages-select nombre_paquete Compila únicamente un paquete específico
colcon list Muestra todos los paquetes del workspace
colcon test Ejecuta pruebas definidas en los paquetes
colcon build --symlink-install En paquetes Python, enlaza el código fuente para evitar recompilar cada vez que se realicen cambios menores

Carpetas generadas por colcon al compilar

Al ejecutar colcon build, se generan 3 carpetas principales en la raíz de tu workspace:

ros2_ws/
├── build/
├── install/
└── log/
Carpeta ¿Para qué sirve?
build/ Archivos temporales de compilación. ROS 2 genera aquí el código intermedio.
install/ Contiene los ejecutables, scripts, bibliotecas y archivos generados. Es la ruta que se enlaza ejecutando source install/setup.bash.
log/ Archivos de registro, advertencias y errores de compilación. Muy útil para tareas de depuración (debugging).

Limpieza de la build

Si en algún momento es necesario limpiar el workspace por completo o reconstruir desde cero:

# Limpiar caché de un paquete específico
colcon build --packages-select mi_pkg_python --cmake-clean-cache

# Limpiar todo el workspace (eliminar compilaciones previas)
rm -rf build/ install/ log/

3. Gestión de Paquetes en ROS 2

¿Qué son los paquetes? Un paquete es la unidad mínima de construcción y compartición en ROS 2. Contiene código fuente, archivos de lanzamiento (launch), configuraciones y puede desarrollarse en Python o C++.

Tipos principales de paquetes:

  • ament_cmake → Orientado para paquetes desarrollados en C++.
  • ament_python → Orientado para paquetes desarrollados en Python.

Creación de un paquete Python desde cero

Para crear un paquete en Python utilizamos el comando ros2 pkg create especificando sus dependencias:

cd ~/ros2_ws/src
ros2 pkg create mi_pkg_python --build-type ament_python --dependencies rclpy std_msgs

Descripción de opciones del comando:

  • mi_pkg_python: Nombre asignado al paquete.
  • --build-type ament_python: Define el tipo de sistema de compilación.
  • --dependencies rclpy std_msgs: Agrega las librerías base de Python para ROS 2 y los mensajes estándar.

Estructura de archivos generada en el paquete:

mi_pkg_python/
├── mi_pkg_python/
│   └── __init__.py
├── package.xml
├── resource/
│   └── mi_pkg_python
├── setup.py
├── setup.cfg
└── test/

Compilación del paquete creado:

cd ~/ros2_ws
colcon build --packages-select mi_pkg_python
echo "source ~/ros2_ws/install/setup.bash" >> ~/.bashrc
source ~/.bashrc

4. Nodo Puente Serial (ROS 2 ↔ ESP32)

Para conectar el ecosistema de ROS 2 con el hardware físico del ESP32 (servomotores), desarrollamos un nodo en Python que actúa como puente de comunicación bidireccional mediante el puerto serial.

  • Suscripción: El nodo se suscribe a los tópicos de ROS 2 (como los ángulos de las articulaciones).
  • Transmisión Serial: Traduce estos mensajes y los envía mediante la librería pyserial hacia el microcontrolador.
